DIAGNÓSTICO DE VENDAS E ATIVAÇÃO DE CLIENTES

Contexto: A pouco tempo iniciei meus estudos no SQL. Meu primeiro passo foi começar um curso básico na Udemy, onde aprendi a montar uma base, adicionar, e fazer consultas simples. Além de conseguir os dados prontos que usei na construção desse projeto. Logo após terminar o curos iniciei uma grande listas de exercios focados principalmente na construção de queries. Nesse contexto selecionei 5 exercicios que fiz, para documentar e monstrar o que aprendi até agora.  

Este projeto analisa uma base de dados de um sistema de vendas com 1.000 clientes cadastrados e 41 vendedores. O objetivo é identificar gargalos operacionais, entender o comportamento dos clientes ativos e propor estratégias para ativação da base. Logo abaixo deixo a estrutura da base usada:
